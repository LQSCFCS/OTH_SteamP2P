# OTH_SteamP2P

为 Over The Hill 接入 Steam P2P 联机方案。模组基于 BepInEx 6（IL2CPP）。

## 简介

《Over the Hill》原版联机走 Photon Fusion 云中继，跨区域组队时数据需绕行中转节点，延迟偏高、容易丢包。本模组把会话内的传输通道切换为 Steam P2P 直连，让玩家之间尽量点对点通信，减少中转跳数。

- 不改动原版大厅、房间码与四人合作流程
- 存档与个人进度记录不受影响
- 客户端方案，不需要专用服务器

## 安装教程

> [!NOTE]
> 先把 BepInEx 装好，再放本模组的 DLL，顺序不要颠倒。

- [ ] 解压 BepInEx 6（IL2CPP）到游戏根目录
- [ ] 启动一次游戏，等它生成 `BepInEx/interop` 后退出
- [ ] 下载本仓库 Release 里的 `OTH_SteamP2P.dll`
- [ ] 放进 `BepInEx/plugins/`
- [ ] 重启游戏，确认日志中插件已加载

```
<游戏目录>/
└── BepInEx/
    ├── plugins/
    │   └── OTH_SteamP2P.dll   ← 放这里
    │   └── Steamworks.NET.dll ← 放这里
    └── interop/
└── over the hill.exe
└── steam_appid.txt            ← 放这里
```

## 使用教程

1. 你和好友**都**安装本模组，版本一致。
2. 双方正常启动游戏，进入原版多人菜单。
3. 通过 Steam 好友邀请或房间码加入同一会话。
4. 客机在进入房间码界面后，需要点几下回车进入房间。
5. 连接建立后传输通道自动切换为 Steam P2P，无需其他额外操作。

> [!TIP]
> 想确认是否生效，看 BepInEx 控制台里本模组的输出信息即可。单人游玩不受影响。
